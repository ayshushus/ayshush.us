Working notes on [mozilla/pontoon#3954](https://github.com/mozilla/pontoon/issues/3954), excluding "system" users (TM, sync, GT) from notifications.

## Summary

Some actions in Pontoon are attributed to automated accounts rather than to people. Those accounts were triggering notifications as if a real contributor had acted, which added noise. The fix filters the system users out so notifications only reflect activity from actual people.
