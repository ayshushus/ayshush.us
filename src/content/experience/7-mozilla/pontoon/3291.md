Working notes on [mozilla/pontoon#3291](https://github.com/mozilla/pontoon/issues/3291), exposing **Completed** strings through Pontoon's API.

## Summary

The API could report several string states but had no way to surface strings marked as Completed, so consumers had to infer that work was finished. The change adds Completed to the states the API returns, which lets external tools read the status directly.

The full working notes, with the investigation and the approach, are in the embedded PDF below.
