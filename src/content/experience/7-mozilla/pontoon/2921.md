Working notes on [mozilla/pontoon#2921](https://github.com/mozilla/pontoon/issues/2921), proposed in [PR #4281](https://github.com/mozilla/pontoon/pull/4281). A shared `string` permalink also carries the filters active when the link was made, so a linked string that no longer matches those filters used to silently redirect elsewhere. The fix surfaces where the string actually lives and lets the user choose.
